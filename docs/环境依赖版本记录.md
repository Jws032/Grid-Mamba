## 3. 后续 README 建议

README 中至少应明确以下兼容组合：

```text
Python 3.9
PyTorch 2.2.0 + CUDA 11.8
mamba-ssm 2.2.0
causal-conv1d 1.4.0
spconv-cu118 2.3.8
_GLIBCXX_USE_CXX11_ABI=False
```

重新安装时应获取与上述 Python、PyTorch、CUDA、ABI 和平台一致的二进制包，
或在目标机器上从源代码重新编译。不要依赖已经删除的本机 wheel 路径。
