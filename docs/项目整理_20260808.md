## 4. 工具目录整理

原 `tools/` 顶层混合了 51 个 Python 文件和 3 个 Shell 文件，包括正式实验、探索性消融、Runtime、分析、候选可视化和测试代码。

整理后的结构为：

```text
tools/
├── experiments/          # 正式训练与消融入口
├── runtime/              # Runtime、复杂度和延迟分析

└── archive/              # 历史开发工具和候选流水线

tests/tools/runtime/      # Runtime 单元测试
```

主要处理包括：

- 去噪、失败案例、SWC 时序和推理策略分析迁入 `tools/analysis/`。
- 非正式开发消融、旧版 Runtime 和阶段特征候选流水线迁入 `tools/archive/`。

- 跨模型 EV-Flying Runtime 调度器保存在
  `Grid_Mamba/tools/runtime/ev_flying/`，由本仓库统一进行版本控制。
- 清除全部 `tools/__pycache__` 和测试缓存。
- 修正 `.gitignore`，确保新的 `tools/analysis/` 不会被旧规则误忽略。
- 不保留旧顶层工具脚本、兼容包装或软链接。

## 5. 核心模型代码收口

本轮以论文最终模型、正式消融配置和现有 checkpoint 为边界，对开发阶段遗留分支进行了收口。论文正文、曲线、Runtime 记录以及 `experiments/` 内的正式配置快照均未修改。

正式代码当前保留的核心路径为：

1. 归一化坐标 MLP 输入编码；
2. Window Sparse Conv 稀疏卷积编码；
3. 多尺度 3D Grid 与 Local Mamba；
4. Grid 相对位置编码；
5. Spatial Window Context、`prev_context` 时序扩散及可选后置空间卷积；
6. 二分类 Point Head。

继续保留的正式消融开关包括：

- `use_local_mamba`；
- `use_grid_pos_encoding`；
- `use_spatial_window_context`；
- `use_temporal_cell_diffusion`；
- `spatial_context_use_conv`；
- `window_size`、`scale_strides` 和 `spatial_context_stride`。

已删除或固定的开发分支包括：

- 删除未采用的 TS 图嵌入、Window KNN 编码器和事件评分模块；
- Window Sparse Conv 固定为正式实验使用的各向同性 GDSC 路径；
- 空间池化固定为正式实验使用的可学习评分池化；
- 时序扩散固定为正式实验使用的 `prev_context` 单源路径；
- Point Head 固定为项目实际使用的二分类输出；
- 删除 4 个依赖上述废弃分支的开发消融入口和 1 个 KNN 专用延迟分析工具；
- 活动配置和实验注册表删除无效字段，正式实验配置快照原样保留。

正式训练、测试、流式推理、Runtime、复杂度分析和可视化调用已经同步到收口后的接口。工作区公共 FRED Runtime 辅助脚本也已移除旧 KNN 参数；独立 `latex` 论文仓库保持冻结，不作修改。
