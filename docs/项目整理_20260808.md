## 5. 核心模型代码收口

本轮以论文最终模型、正式消融配置和现有 checkpoint 为边界，对开发阶段遗留分支进行了收口。论文正文、曲线、Runtime 记录以及 `experiments/` 内的正式配置快照均未修改。

正式代码当前保留的核心路径为：

1. 归一化坐标 MLP 输入编码；
2. Window Sparse Conv 稀疏卷积编码；
3. 多尺度 3D Grid 与 Local Mamba；
4. Grid 相对位置编码；
5. Spatial Window Context、`prev_context` 时序扩散及可选后置空间卷积；
6. 二分类 Point Head。

继续保留的正式消融开关包括：

- `use_local_mamba`；
- `use_grid_pos_encoding`；
- `use_spatial_window_context`；
- `use_temporal_cell_diffusion`；
- `spatial_context_use_conv`；
- `window_size`、`scale_strides` 和 `spatial_context_stride`。

已删除或固定的开发分支包括：

- 删除未采用的 TS 图嵌入、Window KNN 编码器和事件评分模块；
- Window Sparse Conv 固定为正式实验使用的各向同性 GDSC 路径；
- 空间池化固定为正式实验使用的可学习评分池化；
- 时序扩散固定为正式实验使用的 `prev_context` 单源路径；
- Point Head 固定为项目实际使用的二分类输出；
- 删除 4 个依赖上述废弃分支的开发消融入口和 1 个 KNN 专用延迟分析工具；
- 活动配置和实验注册表删除无效字段，正式实验配置快照原样保留。

正式训练、测试、流式推理、Runtime 和可视化调用已经同步到收口后的接口。未形成正式结果且无活动引用的复杂度分析工具已经删除。工作区公共 FRED Runtime 辅助脚本也已移除旧 KNN 参数；独立 `latex` 论文仓库保持冻结，不作修改。

工具内容进一步按正式资产收缩：公共消融引擎删除 S/G/W/C 开发实验表，
EV-Flying 入口只保留 EF45，固定 50 epoch 入口只保留 FULL_SC12，窗口入口
只保留 W25、W50、W100、W200、W300、W800 和 W1600；W400 继续复用
FULL_SC12，不建立重复训练入口。FRED、HLC2、W25、活动数据生成工具和
`latex` 自包含流水线保持不变。EF53/EF54 不再作为活动训练注册项；其诊断
资产和失效清单已随后续 archive 收口删除。
