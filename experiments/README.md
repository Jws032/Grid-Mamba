# Grid_Mamba 实验资产

本目录是 Grid_Mamba 实验资产的规范索引和存储位置。论文内容已经冻结，
本次整理不会修改论文正文、表格、图像、指标名称或已报告数值。

## 目录说明

- `registry/`：受版本控制的实验元数据、别名、协议和迁移记录。
- `runs/`：正式训练、测试、预测及 Runtime 资产。
- `analysis/`：由实验结果派生的诊断与特征分析资产。
- `figures/generated/`：自动生成的预览图；论文正式图仍保存在工作区级
  `latex/` 项目中。
- `portable_artifacts/`：体积较小且不可变的锁文件和索引。仓库原有的
  `artifacts/` 小型资产包继续保留在原位置。
- `archive_pending/`：已被替代、诊断性或旧协议资产，等待后续明确的
  删除决定。

## 已冻结的整理决定

- CP04 正式结果采用 `rerun1`，原始 CP04 归入被替代资产。
- W300 正式结果采用 `rerun2`，原始版本和 `rerun1` 归入被替代资产。
- EV-Flying 只将 EF45 作为正式实验；EF53 和 EF54 属于诊断资产。
- W25 仅作为实验资产保留，不修改论文内容。
- 指标名称 `Acc` 按原记录保留，不进行修改。
- 论文采用的 Runtime 数值继续保留，不同 Runtime 协议分开存放。
- 同一个正式实验目录内的全部文件均保留。
- 首轮删除范围仅限字节完全相同的重复文件、明确的 smoke 输出，以及
  没有可用 checkpoint 的失败实验。

## 迁移规则

每个源位置在资产完成迁移和验证后立即删除。原
`save_model/grid_mamba` 路径只允许出现在迁移/删除审计字段或不可变历史
清单中；不保留兼容目录或软链接。活动配置和工具统一使用
`experiments/` 下的规范路径。

其他旧资产根目录按照“一次处理一个来源”的方式分别收口。
